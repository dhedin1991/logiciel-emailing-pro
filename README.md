# Logiciel Emailing Pro

Application Flutter (Windows + Android) d'envoi d'e-mails multi-comptes.

- **Compilation** : automatique via GitHub Actions (`.github/workflows/build.yml`).
- **Téléchargement** : onglet *Releases*, version « Derniers builds » (APK Android + zip Windows).
- **Tests** : `flutter test` (lancés à chaque build).
